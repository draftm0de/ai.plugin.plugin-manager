# Veröffentlichung über getrennte Repositories

Plugin-Repositories enthalten keine Kataloge. Der Marketplace verweist auf sie. Auch der Plugin Manager hat ein eigenes Repository. sync-plugin/check-plugin prüfen Plugin-Metadaten; sync-marketplace/check-marketplace betreffen Kataloge. Neue Plugin-Quellen zuerst veröffentlichen und prüfen, danach Marketplace-Einträge.
