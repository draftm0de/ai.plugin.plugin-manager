A skill is comparable to a work instruction for an employee.

It describes how the AI assistant is to carry out a certain task, which rules apply and which steps must be followed.

{{PLUGIN_LABEL}} comes with the following skills, one per task. In Claude Code you call them with `/` and their name, in Codex with `$`; both forms are given for every skill. In ChatGPT you describe the task or pick the skill.
